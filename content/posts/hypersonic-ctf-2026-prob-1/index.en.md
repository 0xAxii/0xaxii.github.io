# prob 1

## Overview

`prob 1` is a reversing challenge where you recover a flag from record data whose certain regions are overwritten with random bytes. The provided executable copies the original and then overwrites some regions with random data at a fixed period.

The conditions I confirmed are as follows.

- Category: `reversing`
- Goal: find and recover the structure containing the flag from the record data that was not overwritten with random bytes.

The first thing to check is the overwrite rule. You compute which positions were replaced with random bytes and which remained intact, then reconstruct the file system structure from the surviving data.

## Challenge analysis

Terms used below:

- `ENC`: the length overwritten with random bytes at once. The value is `524288` bytes.
- `SKIP`: the length left intact and skipped in each period. The value is `9961472` bytes.
- `STRIDE`: the overwrite period. Since it is `SKIP + ENC`, it is `10485760` bytes.
- `frame`: a raw LZO1X compressed stream contained within the record data.
- `directory block`: a `4096`-byte block containing ext4 directory entries.
- `inode`: a number that points to a file or directory in the ext4 file system.
- `name`: the name of a directory entry. In this challenge, single-character directory names make up the flag message.

Inspecting the Python bytecode of the PyInstaller-bundled executable shows the following flow.

```python
ENC = 524288
SKIP = 9961472
STRIDE = SKIP + ENC
BUF = 1048576


def overwrite_pattern(f, offset, length):
    f.seek(offset)
    chunk = os.urandom(BUF)
    remaining = length
    while remaining > 0:
        n = min(BUF, remaining)
        f.write(chunk[:n])
        remaining -= n


def make_output_name(path):
    if not path.endswith(".records") and not path.endswith(".record_ids"):
        raise ValueError("not a .records or .record_ids file: " + path)
    return path + ".ENC"


def encrypt(path):
    out = make_output_name(path)
    shutil.copy2(path, out)
    size = os.path.getsize(out)

    with open(out, "r+b") as f:
        offset = 0
        while offset < size:
            offset += SKIP
            if offset >= size:
                break

            length = min(ENC, size - offset)
            overwrite_pattern(f, offset, length)
            offset += ENC

    return out
```

`overwrite_pattern` writes data generated by `os.urandom` directly. So the original content of the overwritten regions cannot be recovered. Since the overwrite positions are fixed, though, the surviving regions can be picked out.

The positions overwritten with random bytes are computed by the following condition.

```text
9961472 <= offset % 10485760 < 10485760
```

So for every `10`MiB, the first `9.5`MiB survives and the last `512`KiB is replaced with random bytes.

The regions of the record data that were not overwritten contain raw LZO1X streams. Streams that decompress correctly produced `8192` bytes of output, which splits into two `4096`-byte ext4 blocks.

I parsed ext4 directory entries with the following structure.

```text
inode     : uint32
rec_len   : uint16
name_len  : uint8
file_type : uint8
name      : name_len bytes
```

To accept something as a directory block, `rec_len` must not go out of the block bounds, and the first two entries must be `.` and `..`. Collecting the blocks that satisfy this condition lets you reconstruct the relationship between a directory `inode` and its child entries.

Among the recovered directories, the flow near the root is as follows.

```text
root
  home -> inode 16

home
  kyouki -> inode 121

home/kyouki
  .bash_logout
  .profile
  .bashrc
  .ssh
  .cache
  f -> inode 2548
  .sudo_as_admin_successful
  .bash_history
```

Here `f` stands out. Following the recovered file system from `home/kyouki/f`, each directory has exactly one child directory, and all of their names are a single character.

## Core idea

The solution collects the surviving compressed blocks and reconstructs part of the file system structure from them.

Analyzing the executable lets you compute exactly where the random overwrites are. Excluding these positions and attempting raw LZO1X streams, some streams yield ext4 directory blocks. Each directory block carries its own `inode` in its `.` entry, so you can build an `inode -> children` dictionary from it.

Then you follow the directory chain starting at `home/kyouki/f` in the recovered file system. The directory names themselves are the message. Continuing to follow directories that have a single child and concatenating the `name`s produces a sentence of the form `flag is ...`.

## Solution process

### Step 1. Computing the overwrite regions

The executable copies the target file, advances by `SKIP`, and overwrites up to `ENC` bytes with random data from that position. It then advances by `ENC` more and repeats the same operation.

The following function decides whether a given physical `offset` was overwritten with random bytes.

```python
ENC = 524288
SKIP = 9961472
STRIDE = 10485760


def corrupt(offset):
    rel = offset % STRIDE
    return SKIP <= rel < SKIP + ENC
```

This gives the set of regions to skip during scanning. Decompression at overwritten positions can't be trusted even if some bytes happen to match, so the `solver` first excludes them with `corrupt(offset)`.

### Step 2. Recovering raw LZO1X streams

The record data appeared to hold compressed streams inside fixed-size slots. The scan starts at `0x4000`-byte slots and takes candidate `offset`s at `0x200`-byte intervals within them.

When attempting raw LZO1X decompression at a candidate position, I treated it as a valid `frame` if it satisfied the following conditions.

```text
Decompression ends at the EOF marker.
The output length is 8192 bytes.
```

An `8192`-byte output can be split into two ext4 blocks. I treated each half as a `directory block` candidate and checked whether it matched the ext4 directory entry format.

### Step 3. Collecting ext4 directory relationships

Parsing a directory block gives the current directory's `inode` from the `.` entry and the list of children from the remaining entries.

```text
entries[0] = "."  -> current directory inode
entries[1] = ".." -> parent directory inode
entries[2:]       -> child entries
```

Since blocks for the same `inode` may be found multiple times, I kept the one whose child list was more fully recovered. This process yields relationships of the form `dirs[inode] = children`.

From these relationships I found `home` under the root directory and `kyouki` under it. After that, `f` among the children of `home/kyouki` looked like the starting point of the flag message.

### Step 4. Tracing the single-character directory chain

Starting from `f`'s `inode` and following child directories, each step has exactly one child. Concatenating the names produces the following chain.

```text
f/l/a/g/ /i/s/ /H/S/{/d/0/c/0/c/b/4/6/0/7/2/0/e/6/f/2/1/d/e/1/d/c/c/f/e/b/3/4/c/a/b/9/1/d/1/c/4/9/9/0/d/b/f/3/4/5/2/f/5/a/9/a/2/0/9/5/b/9/4/3/0/f/a/e/}
```

The slashes only mark the path separators. The actual message is each directory's `name` concatenated as-is.

```text
flag is HS{d0c0cb460720e6f21de1dccfeb34cab91d1c4990dbf3452f5a9a2095b9430fae}
```

## Exploit / Solver

The final `solver` works in the following order.

1. Skip the `offset`s overwritten with random bytes.
2. Attempt raw LZO1X decompression at candidate `offset`s.
3. Parse each `4096`-byte half of the `8192`-byte output as an ext4 directory block.
4. Find the `inode` of `home/kyouki/f`.
5. Follow the chain of directories with a single child, concatenating the names.

The main routines of the solver are below. `decompress` unpacks a raw LZO1X stream and returns `output`, `consumed`, and `eof`.

```python
from __future__ import annotations

import re
import struct
import sys

from lzo1x_raw import decompress


SLOT = 0x4000
SECTOR = 0x200
SCAN_START = 0x6700000
SCAN_END = 0x6810000

ENC = 524288
SKIP = 9961472
STRIDE = 10485760


def corrupt(offset: int) -> bool:
    rel = offset % STRIDE
    return SKIP <= rel < SKIP + ENC


def align_sector(n: int) -> int:
    return (n + SECTOR - 1) & ~(SECTOR - 1)


def valid_name(name: bytes) -> bool:
    if not name or name in (b".", b".."):
        return True
    if b"\x00" in name or b"/" in name:
        return False
    return all(32 <= b < 127 for b in name)


def parse_dir_block(block: bytes):
    entries = []
    pos = 0

    while pos + 8 <= len(block):
        inode, rec_len, name_len, file_type = struct.unpack_from("<IHBB", block, pos)
        if rec_len < 8 or rec_len % 4 or pos + rec_len > len(block):
            return None

        if inode:
            if name_len > rec_len - 8 or file_type > 7:
                return None
            name = block[pos + 8 : pos + 8 + name_len]
            if not valid_name(name):
                return None
            entries.append((inode, file_type, name))
        else:
            if not (rec_len == 12 and name_len == 0 and file_type in (0, 0xDE)):
                return None

        pos += rec_len

    return entries if pos == len(block) else None


def collect_directories(records_path: str):
    dirs = {}

    with open(records_path, "rb") as f:
        slot = SCAN_START - (SCAN_START % SLOT)
        while slot < SCAN_END:
            if corrupt(slot):
                slot += SLOT
                continue

            f.seek(slot)
            buf = f.read(SLOT + 0x3000)
            rel = 4

            while rel < SLOT and rel + 16 <= len(buf):
                offset = slot + rel
                if (
                    offset < SCAN_START
                    or offset >= SCAN_END
                    or corrupt(offset)
                    or buf[rel : rel + 16].count(0) == 16
                ):
                    rel += SECTOR
                    continue

                try:
                    res = decompress(buf[rel:], max_out=8192)
                except Exception:
                    rel += SECTOR
                    continue

                if res.eof and len(res.output) == 8192:
                    for base in (0, 4096):
                        entries = parse_dir_block(res.output[base : base + 4096])
                        if (
                            not entries
                            or len(entries) < 2
                            or entries[0][2] != b"."
                            or entries[1][2] != b".."
                        ):
                            continue

                        inode = entries[0][0]
                        children = entries[2:]
                        if inode not in dirs or len(children) > len(dirs[inode]):
                            dirs[inode] = children

                    rel += align_sector(res.consumed + 4)
                else:
                    rel += SECTOR

            slot += SLOT

    return dirs


def find_child(dirs, parent: int, name: bytes) -> int:
    for inode, _file_type, child_name in dirs[parent]:
        if child_name == name:
            return inode
    raise RuntimeError(f"missing child {name!r}")


def recover_message(records_path: str) -> str:
    dirs = collect_directories(records_path)

    home = find_child(dirs, 2, b"home")
    user = find_child(dirs, home, b"kyouki")
    current = find_child(dirs, user, b"f")

    parts = ["f"]
    seen = set()

    while current not in seen:
        seen.add(current)
        children = dirs.get(current, [])
        if not children:
            break
        if len(children) != 1:
            raise RuntimeError(f"unexpected branch at inode {current}")

        current, _file_type, name = children[0]
        parts.append(name.decode("latin1"))

    return "".join(parts)


def main() -> int:
    message = recover_message(sys.argv[1])
    match = re.search(r"HS\{[^}]+\}", message)
    if not match:
        raise RuntimeError(f"flag not found in {message!r}")

    print(message)
    print(match.group(0))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
